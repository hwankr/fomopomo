# 뽀모도로 도중 작업 완료하고 이어하기

진행 중인 집중 타이머에서 **작업 완료 · 다음 작업**을 누르면 현재 작업의 시간을 기록하고 작업을 완료한다. 남은 시간은 일시정지되며, 다음 작업을 선택하면 같은 뽀모도로를 이어서 시작한다. 작업 목록에서 현재 작업의 완료 체크를 눌러도 같은 흐름을 사용한다.

예를 들어 A로 25분을 시작해 20분 뒤 완료하면 A에 1,200초를 기록하고 남은 5분에서 멈춘다. B를 선택하면 5분을 진행해 B에 300초를 기록한다. 집중 시간이 끝났을 때 사이클이 한 번 증가하고 기존 휴식 설정을 따른다. B는 시간 종료만으로 완료 처리하지 않는다.

## 선택과 복원

- 다음 작업 목록에는 미완료 일간·주간·월간 작업과 장기 과제의 미완료 세부 작업을 표시한다.
- 목록을 닫으면 일시정지를 유지한다. 타이머의 **다음 작업 선택**으로 목록을 다시 연다.
- 목록을 닫거나 새로고침해도 남은 시간과 이미 기록한 시간을 보존한다.
- 다음 작업이 없으면 목록을 닫고 계획에서 할 일을 추가한 뒤 다시 선택한다.
- 작업 완료 요청이 실패하면 타이머는 멈춘 상태를 유지하고 재시도할 수 있다. 재시도는 완료 상태를 명시적으로 설정하므로 완료된 작업을 다시 미완료로 바꾸지 않는다.

## 기록 규칙

- 작업별 기록은 별도의 저장 배치로 만든다. 첫 임시 저장부터 작업 이름·ID·과목과 시간 구간을 고정한다.
- 기록을 임시 저장으로 넘긴 즉시 해당 시간을 소비 처리한다. 최종 종료·새로고침·재시도에서 같은 시간을 다시 기록하지 않는다.
- 서로 다른 기록의 전송은 순서대로 처리하며, 같은 기록의 동시 저장은 합친다. 실패한 기록은 기존 임시 보관함과 재시도 경로를 사용한다.
- 다른 기기에 알리는 진행 시간은 아직 기록하지 않은 구간을 기준으로 한다. A의 20분을 저장한 뒤에는 B의 남은 5분이 진행 중인 구간이 된다.
- 기존 서버의 최소 10초 기록 규칙을 유지한다. 현재 작업의 미저장 시간이나 남은 시간이 1~9초이면 전환을 진행하지 않고 안내한다.
- 일시정지로 생긴 짧은 조각과 초 단위 반올림 때문에 총 시간이 사라지지 않도록 구간 합계를 보정한다. 각 공부일에 10초 이상이 있으면 오전 5시 경계를 유지한다. 한 공부일의 조각 전체가 10초 미만이면 서버 제한상 인접 구간에 합쳐야 하므로 그 소량의 시간은 합쳐진 구간의 종료 공부일에 포함된다.

데이터베이스 스키마 변경이나 새 의존성은 필요하지 않다.

## 검증

- 실제 타이머·기록 훅을 사용하는 통합 테스트에서 A/B 시간·과목 분리, 사이클·휴식, 저장 실패·중복 클릭, 목록 닫기·새로고침, 완료 처리 재시도 등을 확인한다.
- 기록 훅 테스트는 저장 대기열, 계정 분리, 최초 메타데이터 보존, 짧은 구간·반올림·공부일 경계의 시간 합계를 확인한다.
- 브라우저 검증은 외부 저장 요청을 격리된 예시 응답으로 대체해 실행한다. A 1,200초와 B 300초, 선택 중 60초 경과 및 새로고침 후 남은 300초 유지, 1회 사이클 및 짧은 휴식 진입, 390px 화면의 가로 넘침 없음을 확인했다. 실제 사용자 기록을 테스트용으로 변경하지 않았다.
